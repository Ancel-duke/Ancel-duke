# 💫 About Me:

Hi, I'm Ancel, a software engineer who genuinely enjoys building things. Whether it's an AI-powered platform, a developer tool, or a full-stack application, I love the process of turning an idea into something people can actually use. I'm particularly interested in AI, distributed systems, and backend engineering, but I also enjoy creating intuitive user experiences that make complex technology feel simple. Every project I work on is an opportunity to learn something new, improve my craft, and build software that's both practical and meaningful. Outside of coding, you'll usually find me exploring emerging technologies, contributing to open source, or sketching out ideas for the next project I want to bring to life.
